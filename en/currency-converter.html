How is currency conversion calculated?

The current rate table is normalized to a common TRY reference base. The calculator first finds the source amount’s TRY-equivalent reference value, then divides it by the target currency’s TRY rate. The same method works for both TRY pairs and cross-currency pairs.

Core calculation
TRY-equivalent value = Amount × Source rate
Target amount = TRY-equivalent value ÷ Target rate
USD → TRY example
If 1 USD = 40 TRY, then 100 USD corresponds to 4,000 TRY.
USD → EUR cross-rate example
If USD/TRY is 40 and EUR/TRY is 50, then 100 USD corresponds to 4,000 ÷ 50 = 80 EUR.

Important: Example numbers only explain the method; they are not current rates. Actual calculations use the data source shown in the result panel.

What is a cross rate?

The rate between two currencies

A cross rate expresses the value of one currency in another without requiring a direct pair quote. Examples include USD/EUR, EUR/GBP and CHF/USD. The calculator derives the pair from each currency’s value against the common TRY reference base.

What does the inverse rate show?

The cross rate answers “How many target units equal 1 source unit?” The inverse rate reverses the relationship and shows how many source units equal 1 target unit.

Why can central-bank, bank and exchange-service rates differ?

There is no single executable exchange rate. The provider, trade direction, payment method and market conditions can change the final amount. This calculator uses the selling or reference values available from its data source and does not guarantee a transaction quote.

How do spreads and fees affect the result?

Exchange-rate spread

The difference between a provider’s buy and sell rates is the spread. When you buy foreign currency, the provider’s sell rate normally applies; when you sell it back, the buy rate normally applies. That is why an immediate round trip commonly produces a loss.

Additional costs

Some transactions may include commissions, taxes, card-processing charges or weekend pricing adjustments. The calculator does not estimate these automatically, so check the provider’s final amount before transacting.

What should you know about gold and silver conversions?

When the active data source provides gram-based gold and silver values, the calculator can include them as XAU and XAG options. These are precious-metal reference values rather than currencies. Results do not include retail workmanship, product purity, physical-delivery costs or dealer spreads.

  • Do not confuse gram gold with troy-ounce gold; many international sources publish precious-metal prices per troy ounce.
  • Physical gold products can include workmanship charges and retail premiums.
  • Silver prices can vary with purity, product type and physical-delivery costs.
  • Check the source and rate type shown in the result panel for every calculation.

Common currency-conversion mistakes

Treating a reference result as an executable quote

The calculated value is not a guaranteed quote from a bank or exchange service. Use the provider’s final transaction screen for the amount you can actually execute.

Mixing up buy and sell directions

When buying foreign currency, the provider’s sell rate matters; when selling it, the buy rate matters. Changing direction can change the applicable rate.

Ignoring the data timestamp

In fast-moving markets, an older rate can become stale quickly. The calculator therefore shows the source and data time prominently.

Ignoring fees

Card, transfer or platform fees can change the effective conversion rate even on relatively small transactions.

Frequently Asked Questions

Which exchange rates does this converter use?

The calculator first tries Hesapica's current rates.json file on the same site. If it is unavailable, the calculator can try supported fallback sources. The active source, rate type and update time are shown in the result panel.

How is a cross rate calculated?

The source amount is converted through the common TRY reference base, then divided by the target currency’s TRY rate. This allows pairs such as USD/EUR to be calculated without a direct quote.

Why can a TCMB reference rate differ from a bank rate?

TCMB data can be indicative. Banks, card issuers and exchange services can apply their own buy/sell spreads, fees and transaction conditions.

Are rates published per 100 units handled correctly?

Yes. When the TCMB XML source is used, the Unit field is taken into account and the published quote is normalized to one currency unit.

What happens if live rates cannot be loaded?

If current sources cannot be reached, the last successful browser-cached dataset may be used for up to 48 hours. Older cached data is not used automatically.

Are fees and exchange-rate spreads included?

No. The calculator provides a reference conversion. Bank fees, card rates, taxes, buy/sell spreads and other transaction costs are not included.

Are gold and silver results the same as retail dealer prices?

No. The result uses the supported source’s reference gram value. Retail workmanship, product premiums and buy/sell spreads are not included.
